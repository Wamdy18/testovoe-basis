# Тестовое задание для МКК Базис

Краткое описание проекта: To-do приложение. На главной странице отображаются заметки, которые содержат до 5 пунктов to-do (остальные скрыты). На странице редактирования есть возможность изменить название заметки, добавить/отредактировать/удалить пункты to-do, удалить заметку, сохранить заметку, отменить редактирование заметки. Есть черновики. Данные хранятся в localStorage. Есть возможность Отмены и Повторения действий (Ctrl+Z, Ctrl+Shift+Z), работает с клавиатуры.
Стек: Nuxt 4, TypeScript, Pinia, Vitest

Подробное описание проекта в файле TestovoeZadanie.pdf
Запуск - docker-compose up
